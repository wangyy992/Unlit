# 暗室

一个纯静态的休闲游戏站。原生 HTML/CSS/JS + Canvas，**零依赖、零构建** —— 把仓库直接丢到 GitHub Pages / Cloudflare Pages 就能跑。

## 《光与影》

双人同屏的合作解谜游戏，目前 5 关。

**光灵**离开光就会消散，**影灵**被光照到就会消散。灯可以推着走 —— 推动一盏灯，就同时改变了两个人的路。两人必须**同时**站在各自的门里才算过关。

| | 移动 | 跳跃 |
|---|---|---|
| 光灵 | `←` `→` | `↑` |
| 影灵 | `A` `D` | `W` |

`R` 重来，`M` 静音。需要物理键盘，手机端暂未支持触屏。

### 关卡

| # | 名称 | 教的东西 |
|---|---|---|
| 1 | 分道 | 两种角色的生存规则 |
| 2 | 借光 | 灯可以推，推灯就是在改路 |
| 3 | 互锁 | 压力板 / 机关门，谁先动的顺序 |
| 4 | 垫脚石 | 灯也是能站上去的箱子 |

## 加关卡

关卡就是一段字符网格，改 `src/levels.js` 即可，不用碰引擎：

```
#   墙                    .   空气
L   光灵出生点            l   光灵的门
U   影灵出生点            u   影灵的门
*   固定灯（挂墙上）      o   可推动的灯
1-4 压力板                A-D 机关门（A 对应压力板 1）
```

每关的所有行必须等长。

### 设计约束

这些数字由引擎常量决定，改关卡时要守住：

- 最大跳跃高度 **80px = 2.5 格** → 2 格台阶跳得上，3 格跳不上
- 站在灯上可达 **110px = 3.4 格** → 3 格墙必须借灯才能翻
- 最大水平跳跃 **124px = 3.9 格** → 缺口最多 3 格
- 护盾 **0.4 秒**耗尽 → 光柱缝隙要有 3 格宽，否则角色一跃而过，机制形同虚设
- **固定灯是实心的**，不能放在地板行上，否则会堵死通路
- 门必须放在角色真正站立的那一行（脚下有地），否则判定区够不着

## 实现要点

- **光影**：每盏灯把面向自己的墙面边缘沿光线方向挤出成阴影多边形，用 `destination-out` 从光照图里挖掉。相邻同向墙面会先合并成长边，减少多边形数量；光照图只在灯移动或机关门开合时重算。
- **光暗判定**：与渲染分开，用灯到角色的视线检测 + 距离衰减累加光强。判定阈值对应半径的 55%，也就是肉眼可见的亮核。
- **手感**：coyote time（离地后 0.09s 仍可起跳）、跳跃缓冲（落地前 0.1s 按跳生效）、松键断跳。
- **音效**：WebAudio 现场合成，不需要素材文件。
