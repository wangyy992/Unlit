# 暗室

一个纯静态的休闲游戏站。原生 HTML/CSS/JS + Canvas，**零依赖、零构建** —— 把仓库直接丢到 GitHub Pages / Cloudflare Pages 就能跑。

## 《光与影》

双人同屏的合作解谜游戏，目前 18 关。

**光灵**离开光就会消散，**影灵**被光照到就会消散。灯可以推着走 —— 推动一盏灯，就同时改变了两个人的路。两人必须**同时**站在各自的门里才算过关。

| | 移动 | 跳跃 |
|---|---|---|
| 光灵 | `←` `→` | `↑` |
| 影灵 | `A` `D` | `W` |

`R` 重来，`F` 全屏，`M` 静音。需要物理键盘，手机端暂未支持触屏。

每关的设计意图写在 `levels.js` 的 `hint` 字段里，鼠标悬停选关按钮可以看到。

## 加关卡

关卡就是一段字符网格，改 `src/levels.js` 即可，不用碰引擎：

```
#   墙                    .   空气
L   光灵出生点            l   光灵的门
U   影灵出生点            u   影灵的门
*   固定灯（挂墙上）      o   可推动的灯
1-4 压力板（踩一次永久开门）
a-d 常压板（压住才开，松开就关；灯可以当配重）
A-D 机关门（A 对应压力板 1 或常压板 a）
```

每关的所有行必须等长。

### 设计约束

这些数字由引擎常量决定，改关卡时要守住：

- 最大跳跃高度 **80px = 2.5 格** → 2 格台阶跳得上，3 格跳不上
- 站在灯上可达 **110px = 3.4 格** → 3 格墙必须借灯才能翻
- 最大水平跳跃 **124px = 3.9 格** → 缺口最多 3 格
- 护盾 **0.28 秒**耗尽 → 光柱缝隙要有 3 格宽。这个值不能放宽：角色跳跃穿过光柱的暴露时间约 0.34 秒，护盾一旦超过它，会跳的玩家就能硬闯光柱
- 靠「光斑」赶路时，两块光斑之间的黑暗不能超过 **53px**（0.28 秒护盾 × 190px/s 移速）。留 20% 余量比较稳，即 ≤44px
- 影灵走廊至少 **4 格高**。只有 3 格时跳跃会撞顶、上升速度归零，滞空时间从 0.65 秒缩到 0.52 秒，水平距离只剩 98px —— 而跨 3 格缝需要 100px
- **固定灯不能放在光柱缝隙的正下方**。对「站立」判定是安全的（缝里本来就站不了人），但影灵必须飞越那段空域，会被正射的光柱烤死
- **固定灯是实心的**，不能放在地板行上，否则会堵死通路
- 门必须放在角色真正站立的那一行（脚下有地），否则判定区够不着
- 压力板要放在角色**走得到**的地方 —— 从高处跳下来是抛物线，单格板会被整个越过，落点附近的板至少铺 2 格

## 实现要点

- **光影**：每盏灯把面向自己的墙面边缘沿光线方向挤出成阴影多边形，用 `destination-out` 从光照图里挖掉。相邻同向墙面会先合并成长边，减少多边形数量；光照图只在灯移动或机关门开合时重算。
- **光暗判定**：与渲染分开，用灯到角色的视线检测 + 距离衰减累加光强。判定阈值对应半径的 55%；渲染的亮度曲线必须在这个边界之后迅速收掉，否则会出现「看着危险其实安全」的光晕，玩家读不准哪里能站。
- **手感**：coyote time（离地后 0.09s 仍可起跳）、跳跃缓冲（落地前 0.1s 按跳生效）、松键断跳、跳跃时的挤压拉伸与落地接触阴影。
- **画面**：墙体按坐标哈希做逐格明暗抖动并加受光顶面与背光底边，避免大片纯色；门画成暗内腔 + 发光门框（门是墙上的洞，内部暗才能在明亮区域里也看得见）；机关门用流动的能量条表示「还关着」；光照区内飘浮尘埃，每帧只抽样更新五分之一以控制视线检测的开销；全局叠一层暗角。
- **音效**：WebAudio 现场合成，不需要素材文件。脚步用带通滤波的白噪声（纯振荡器出不来踩踏的质感），并按**位移**而非时间触发 —— 按时间触发的话，推灯减速时步频不变会很假。另有一层环境配乐：A 小三和弦的低频长音（三个音轻微失谐产生缓慢拍频）经缓慢扫动的低通滤波器，配上每 9~19 秒随机一声远处的钟。音效事件要铺满常见操作（开场、落地、推灯、开门、进门、开关反馈），否则玩家可能整关听不到任何声音 —— 第 1 关根本不需要跳，而跳跃一度是唯一的发声点。
- **音频解锁**：AudioContext 必须等到首次用户手势才创建，页面载入时创建会得到一个挂起的上下文，之前排的声音全部丢失。
